# Chess Tic-Tac-Toe

A hybrid game combining chess piece placement and movement with tic-tac-toe win conditions. Built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run lint` — run ESLint
